SVPM LAB BUILDING — 3D + 2D INDOOR NAVIGATION DEMO

START ON WINDOWS
1. Extract the ZIP to a normal folder.
2. Internet connection is required for Three.js CDN imports.
3. Double-click RUN_LOCAL_SERVER.bat.
4. In Edge/Chrome open http://localhost:8000
5. Choose Current Location / Start Room and Destination Room.
6. Press Get Directions. The suggested corridor path appears in blue.
7. Press Start Navigation. Use Next Checkpoint as you physically reach each indicated point; voice guidance speaks turn instructions.
8. Press Wrong Direction / Re-route to demonstrate a red off-route warning and spoken reroute prompt.
9. Allow browser sound/voice if prompted. Speech uses the browser's built-in speech engine.

IMPORTANT LIMITATIONS
- This is a demonstration model with schematic geometry and a simplified corridor-loop route. It is not CAD-exact and the route is not a surveyed or validated real-world shortest path.
- Indoor GPS is generally not reliable enough for room-level tracking. This demo does NOT automatically know where a person is walking. Progress is checkpoint-confirmed by the user; wrong-direction alert is manually triggered. Automatic detection requires room/corridor QR checkpoints or installed BLE/UWB positioning and a validated indoor map.
- The voice prompts are generated by the browser's speech synthesis. Availability/voice depends on the device and browser.
- One common QR code only opens the website; it cannot determine the current room. User selects starting room manually.
- This package is independent of V1 and does not alter the existing GitHub Pages URL, repository, or common QR code.
